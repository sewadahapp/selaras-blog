An audiovisual performance about coastlines that keep changing. The live set
uses sampled voices, modular synthesis, and projected images gathered near the
water.

![A Moog DFAM and Mother-32 semi-modular synthesizer on a desk. Photograph via Wikimedia Commons, CC0.](/images/moog-drummer-from-another-mother-dfam-mother.jpg)

Between takes the set runs through an effects rack that predates the project —
patches taped down, levels set by ear.

![An effects rack with a Yamaha SPX90 and a Peavey DPM Spectrum in a home studio. Photograph by Klara Kopf, CC BY 2.0.](/images/effects-rack-yamaha-spx90-peavey-dpm-spectrum.jpg)

The performance is played, not reproduced: each night's tide chart sets the
tempo, and the projected maps are redrawn live from whatever the local weather
and clock hand the rig.
